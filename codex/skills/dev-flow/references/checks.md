# Check permissions

Agree local integration checks in the request, plan or standing repository
permission: commands, scope and external resource limits. Reuse that permission;
ask again only to extend it. Standing offline permission requires listed commands
and resource limits; past runs establish no permission. Narrower task restrictions
prevail.

Other integration, end-to-end and load/performance tests require explicit approval;
propose them together and explain why cheaper proof is insufficient. GPU experiments
and deployment remain separate gates. Do not relabel tests as smoke or treat test
approval as external access.
